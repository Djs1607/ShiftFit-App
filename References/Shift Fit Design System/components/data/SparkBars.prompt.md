Axis-free bar chart for trends inside a Card (weekly tonnage, sleep hours, session count).

```jsx
<SparkBars data={[12,18,9,22,16,24,20]} labels={['M','T','W','T','F','S','S']} highlightLast />
```

Bars sit at 62% opacity; the highlighted bar goes full-opacity amber. Never add a legend — label with a MetricTile above it.

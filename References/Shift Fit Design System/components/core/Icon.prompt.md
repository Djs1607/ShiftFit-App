Renders a Lucide glyph as a currentColor mask — use it for every icon in Shift Fit; never paste inline SVG paths.

```jsx
<Icon name="dumbbell" size="lg" />
<Icon name="moon" color="var(--sf-amber-500)" />
```

Sizes: sm 16 / md 20 / lg 24 / xl 32, or a px number. Icons inherit text colour, so put them inside the element whose colour they should follow. Shift Fit's canonical glyph set: dumbbell, activity, moon, sun, battery-low, timer, trending-up, heart-pulse, calendar-days, chevron-right, plus, bed.

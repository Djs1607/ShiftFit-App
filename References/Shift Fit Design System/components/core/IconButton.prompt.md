Icon-only control for top bars, card corners and media rows. Always pass `label`.

```jsx
<IconButton icon="bell" label="Notifications" />
<IconButton icon="plus" variant="filled" size="lg" label="Log set" />
```

Ghost by default; `filled` sits on a raised surface with a hairline. Keep to 44px hit area on mobile by using size lg or adding padding around size md.

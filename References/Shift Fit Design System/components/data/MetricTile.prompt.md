The standard number readout. Numbers are ALWAYS mono with tabular figures so digits don't jitter as they tick.

```jsx
<MetricTile label="Weekly tonnage" value="18,420" unit="kg" delta="+6.1%" trend="up" size="lg" />
```

One `lg` hero metric per screen; `sm`/`md` for grid tiles. Green delta = improvement, red = decline — never colour the value itself.
